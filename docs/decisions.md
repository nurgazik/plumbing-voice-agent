- 2026-09-14 Values from the rules file reach the n8n workflows through `workflows/build.js`, which writes `const RULES = {...}` between block-comment markers inside a Code node's JavaScript, and `--check` fails if a copy is stale. First attempt used a top-level constant and template expressions in the SDK file; n8n's SDK parser is a restricted evaluator that allows no function declarations, no array or string methods, and gives no visibility into whether template expressions are substituted, so the vision workflow's request-preparation Set node became a Code node that assembles the prompt in runtime JavaScript. Same principle as agent/push.ts rendering the prompt: one source, rendered at build time, checked before deploy.
